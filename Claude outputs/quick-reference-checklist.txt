⚙️ FILTER LOGIC (What Should Happen)
────────────────────────────────────────────────────────────────────────────────

LOGIC:  Show tours WHERE (category matches) AND (area matches) AND (city matches)

EXAMPLES:

  [All] + [All] + [All Cities]     → Show ALL tours

  [Pizza] + [All] + [All Cities]   → Show PIZZA tours from all areas & cities

  [All] + [Monti] + [All Cities]   → Show ALL tours in Monti area

  [Pizza] + [Monti] + [Rome]       → Show PIZZA tours in MONTI area in ROME

  [Pasta] + [Testaccio] + [Vatican]→ Show PASTA tours in TESTACCIO in VATICAN


SELECTION BEHAVIOR:

  ✅ User selects one button in any section
  ✅ That button highlights green (#2D7C3F background, white text)
  ✅ Other buttons in same section turn gray
  ✅ Selections in OTHER sections DON'T change
  ✅ Results filter instantly based on ALL 3 selections
  ✅ Selection PERSISTS even if user switches to different section


PERSISTENCE RULE (MOST IMPORTANT):

  IF User selects "Pizza" AND "Monti" AND "Rome"
  THEN clicks another button in ANY section
  THEN all 3 selections remain active ✅

  If this doesn't work → BUG

🎨 STYLING RULES
────────────────────────────────────────────────────────────────────────────────

BUTTONS:
  • Padding: 10-12px horizontal, 8px vertical (bigger touch targets)
  • Border Radius: Same as existing site style
  • Font Size: 14px
  • Font Weight: Medium (500)

SELECTED STATE:
  • Background: #2D7C3F (green, same as site)
  • Text: White
  • Transition: 150-200ms smooth color change

UNSELECTED STATE:
  • Background: #E8E8E8 or #F0F0F0 (light gray)
  • Text: #333333 (dark gray)

BUTTON SPACING:
  • Gap between buttons: 8-12px
  • Sections vertical gap: 20px

RESPONSIVE:
  • Mobile (<480px): Full-width scrollable carousel, swipe enabled
  • Tablet (480-768px): Scrollable with scroll indicators
  • Desktop (>768px): All visible or scrollable with arrow buttons

════════════════════════════════════════════════════════════════════════════════

🚫 ANIMATIONS - STRICT RULES
────────────────────────────────────────────────────────────────────────────────

ALLOWED:
  ✅ Button click effect: 150ms fade/scale (user feedback)
  ✅ Hover state: Subtle color change (desktop only)
  ✅ Selection highlight: 200ms smooth transition
  ✅ Carousel scroll: Native browser smooth scroll

FORBIDDEN:
  ❌ Page jumps or shifts
  ❌ Slide-in animations from sides
  ❌ Fade animations on load
  ❌ Auto-scroll or carousel animations
  ❌ Random scale/zoom effects
  ❌ Bouncy or springy animations

RULE: Motion should be INVISIBLE. User shouldn't NOTICE animation,
      only feel that action was registered.
